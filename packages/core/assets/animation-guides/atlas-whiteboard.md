# Whiteboard Explainer

Original Vidmyo visual direction:
Draw explanations as progressive marker strokes on a light board. Use wobbly outlines, hand-lettered labels and cause-and-effect diagrams.

Motion direction: use anticipation, purposeful transitions and scene-specific actions to explain the narration. Preserve materials, palette and object identity across shots. Code must obey the host frame contract; reference demonstrations are inspiration, not assets to reuse.
