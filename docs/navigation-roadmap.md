# Vidmyo navigation roadmap

## Explore Apps

Hidden from the main navigation on 2026-09-04. The current implementation is inherited from the MuAPI starter and is not yet a curated Vidmyo experience. Its source remains available for a future product review rather than being deleted.

## Workflows

Hidden from the main navigation on 2026-09-04. The current area is a MuAPI cloud workflow builder, not an automation layer for Vidmyo's local media tools. Its source and direct routes remain dormant rather than being deleted.

A future Vidmyo-native version could become **Automations**: reusable pipelines such as import, transcribe, clean or clip, frame, caption, and export.

## First sellable release checkpoint

- [ ] When Vidmyo v1 is complete and ready to start selling, explicitly revisit local **Automations**. Validate with early users whether saved or batch pipelines would make video creation materially faster or easier before rebuilding the feature.
